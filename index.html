  • CarPi: CAN Bus Telemetry

    Personal project · In progress

    A headless Raspberry Pi on my car's OBD-II port that requests live engine data from the ECU over CAN (MCP2515 + Linux SocketCAN) about 8 times a second and logs one CSV per drive. Every decoded signal is checked against a physical reference before a run is trusted, and a pandas pipeline, tested and deployed by GitHub Actions, turns the logs into before/after comparisons for an engine repair.
